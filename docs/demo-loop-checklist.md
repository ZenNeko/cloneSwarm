# Demo Loop Checklist — เกณฑ์ผ่านเฟส 1

> เขียน 2026-10-11 · ใช้คู่กับแผนเดโม Next Fest มิ.ย. 2027
> ✅ ผ่าน · ❌ ไม่ผ่าน · ⬜ ยังไม่ได้ทำ

**เกณฑ์ผ่านเฟส 1:** เล่นจบครบรอบ 10 ครั้ง โดย 3 ครั้งเป็น co-op หลายเครื่อง
และไม่มีบั๊กที่ทำให้เล่นต่อไม่ได้

**ขอบเขตเดโมที่ตัดสินแล้ว:** ฮีโร่ 3 ตัว (Riven, Gunner, Hunter) · ความยาก Easy / Normal / Hard ·
แมพ Arena01 แมพเดียว · มี Talent นอกเกม

> ⚠️ **เล่นเป็น host อย่างเดียว = ไม่ได้เทสต์** — ครึ่งหนึ่งของบั๊กที่เคยเจอโผล่เฉพาะบนจอ client
> ทุกครั้งที่เทสต์ co-op ให้จดว่าเห็นอาการบนจอ host หรือจอ client

## A — เมนูก่อนเข้าเกม

- [ ] ⬜ ปุ่มความยากในห้องมี **3 ปุ่ม** (EASY / NORMAL / HARD) ไม่มี SAVAGE / EPIC
- [ ] ⬜ เลือกความยากแล้ว ป้าย ENEMY HP / GOLD เปลี่ยนตาม (Easy ×0.8 · Normal ×1 · Hard ×1.2)
- [ ] ⬜ co-op: host เปลี่ยนความยาก → จอ client เห็นค่าใหม่
- [ ] ⬜ เลือกฮีโร่ได้ครบ 3 ตัว ทั้ง host และ client · ตัวที่ยังไม่ปลดล็อกแสดงราคาถูก
- [ ] ⬜ หน้า Talent: ซื้อได้ ทองลด เลเวลขึ้น

## C — จบเกม

- [ ] ⬜ ฆ่า Main Boss → จอ WIN ขึ้นครั้งเดียว ไม่ซ้ำ
- [ ] ⬜ ทุกคนตาย → จอ LOSE
- [ ] ⬜ จอสรุปทอง: ผลบวกแต่ละบรรทัดเท่ากับยอดรวมพอดี
- [ ] ⬜ บรรทัดความยาก: Easy ติดลบ · Normal ไม่มีบรรทัด · Hard บวก
- [ ] ⬜ co-op: ทุกเครื่องได้ทองเข้าเซฟของตัวเอง
- [ ] ⬜ ออกไปเมนูแล้วเข้าเกมใหม่ได้โดยไม่ต้องปิดเกม

## D — Talent เซฟข้ามรอบ

- [ ] ⬜ ซื้อ talent → ปิดเกม → เปิดใหม่ → เลเวล talent กับทองยังอยู่
- [ ] ⬜ เข้าเกมแล้ว stat ตรงกับ talent (เช่น Health → HP สูงสุดเพิ่ม)
- [ ] ⬜ co-op: talent ของ **client** มีผลจริง (HP ใน HUD ของ host ก็ต้องเห็นค่าที่เพิ่ม)
- [ ] ⬜ Talent Revive: ตายครั้งแรกแล้วฟื้น ครั้งที่สองตายจริง
- [ ] ⬜ Talent Gold: ทองท้ายเกมมีบรรทัด GoldFind เฉพาะคนที่ซื้อ

## E — บัฟชั่วคราวบนจอ client (เดิมคือ Stage 0.1)

อ่านโค้ด 2026-10-11 แล้ว **น่าจะไม่ใช่บั๊กแล้ว** แต่ยังไม่เคยมีใครเห็นด้วยตา:
ความเร็ว · damage · haste ถูกอ่านบนเครื่อง owner และบัฟถูกใส่บนเครื่อง owner ·
regen ถูกอ่านบน server และ `SupportArenaPillar` ใส่ให้ฝั่ง server ด้วย (`pm.IsOwner || isServer`)

เล่นเป็น **client** แล้วดู:

- [ ] ⬜ Riven E (Blade of Exile) → เดินเร็วขึ้นชัดเจน
- [ ] ⬜ Gunner passive ครบ 30 kills → เดินเร็วขึ้น + สกิลคูลดาวน์เร็วขึ้น
- [ ] ⬜ ยืนในวง Support Arena ของ **อีกคน** → เดินเร็วขึ้น + เลือดฟื้น
- [ ] ⬜ augment แบบบัฟชั่วคราว → ตัวเลขดาเมจสูงขึ้นช่วงบัฟ

ถ้าข้อไหนไม่ผ่าน ให้จดว่าใครเป็นคนวางบัฟ (ตัวเอง / คนอื่น) — คือข้อมูลที่ต้องใช้หาต้นเหตุ
