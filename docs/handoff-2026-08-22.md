## 2 · สองไฟล์ที่แก้แล้วแต่ยังไม่ commit

ทั้งคู่เป็นงานซ่อมล้วน ไม่แตะตัวเลขบาลานซ์ แต่ยังไม่ได้ push ขึ้น PR #15

### ChargeManager — สองบั๊ก

**`weapon?.` ใช้ `?.` ของ C#** ซึ่งเทียบ reference null ล้วน · object ที่ถูก `Destroy` แล้วไม่ใช่ reference null มันจะเรียกเมธอดต่อแล้วไปตายที่ `transform` ข้างใน · `ReplaceWeapon` (อัปเป็น Super) ทำลายอาวุธเก่าทิ้ง แล้ว `FindWeapon` โพลทุก 1 วินาที จึงมีหน้าต่างที่ชี้ของที่ตายแล้ว → เปลี่ยนเป็น `!=` ของ Unity

**หลอดที่เต็มถูกทิ้งเงียบ** — `CurrentCharge = 0f` เกิดก่อนเช็ก weapon · ช่วง 0.5 วิแรกหลัง spawn และหน้าต่างอัปเป็น Super หาอาวุธไม่เจอ ผู้เล่นเดินครบระยะแล้วไม่มีอะไรเกิดขึ้น → ล้างหลอดเฉพาะตอนยิงจริง ไม่เจอก็คาไว้ที่ `MaxCharge`

*ตั้งใจไม่เรียก `FindWeapon()` ตรงนั้นเพื่อไม่ต้องรอโพล* — `ChargeManager` อยู่บน `player.prefab` ที่ทุกตัวละครใช้ร่วมกัน Hunter/Gunner ไม่มี `BunnyHopWeapon` เลยจะเข้าเงื่อนไขนี้ทุกเฟรม กลายเป็น `GetComponentInChildren` รายเฟรมตลอดรัน

### GameSessionManager — regression ที่ทำเอง

การเลื่อน player spawn ผูกไว้กับ `OnLoadEventCompleted` / `OnSynchronizeComplete` ซึ่งต้องให้ **NGO เป็นคนโหลดซีน** ถึงจะยิง · `WeaponTestScene` เปิดอยู่แล้ว `AutoHost` แค่ `StartHost()` เฉยๆ → ไม่มีใคร spawn player

เพิ่ม `OnClientConnectedCallback` ที่ spawn ให้ถ้า active scene ไม่ใช่ซีนเมนู · ครอบทุกทางเข้าแล้ว

```
กด Play ในซีนเกมตรงๆ  →  StartHost → client connect → spawn ทันที      ใหม่
เมนู → StartGame       →  connect ตอนอยู่ MenuScene → ข้าม
                          แล้ว OnLoadEventCompleted ค่อย spawn         เหมือนเดิม
late join              →  OnSynchronizeComplete                        เหมือนเดิม
```

## 3 · สิ่งที่อยู่ใน PR #15 แล้ว

### UI

`CarouselBase` เป็นกลไกร่วม (abstract) — `CharacterCarousel` กับ `MapCarousel` สืบทอด บอกแค่ "มีกี่ชิ้น" กับ "ผูกข้อมูลยังไง" ผ่าน 4 hook · คณิตศาสตร์ offset/wrap/snap มีสำเนาเดียว

ตัวที่เลือกอยู่กลางเสมอ วนไม่รู้จบ · ลาก 1:1 + snap · ลูกกลิ้ง · ปุ่ม ▲▼ · คลิกใบข้างเพื่อหมุนมากลาง · scale/alpha ไล่ตามระยะ · ปิด mask ใบกลางให้ภาพล้นกรอบ

**คอมมิตเกิดหลัง snap นิ่งเท่านั้น** ลากยาวผ่านหลายตัวยิง RPC ครั้งเดียว

เพิ่ม `MapSelectUI` + `MapCardUI` · `CharacterSelectUI` ได้แผง stat/แท็บ/ปุ่ม Select · `LobbyUI` ได้ปุ่มไปแท็บ MAP กับภาพแมพ/ตัวละคร

### Netcode

เดิม NGO spawn player ทันทีที่กด PLAY ใน MenuScene ซึ่งเกิด**ก่อน**เลือกตัวละคร · player object เป็น dynamic NetworkObject ไม่ถูกทำลายตอนเปลี่ยนซีน `_charIndex` เลยค้าง — เลือก Riven แล้วเข้าเกมได้ Hunter

**ผลพลอยได้:** เดิมกด Q/E ในล็อบบี้ยิง ability จริงไปพร้อมสลับแท็บ และ WASD ขยับตัวละครที่มองไม่เห็นแล้วลากตำแหน่งนั้นข้ามซีน

### Riven — เทียบสเปกต้นทาง LoL Swarm

ตัวแปลงหน่วย: Valor RANGE 250 ต้นฉบับ = `ld.range` 4 ของเรา → **1 หน่วย Unity ≈ 62.5 หน่วย Swarm**

- **Runic Blade กลับทิศ** — ต้นฉบับ "based on how close they are" ของเราให้โบนัสตอนอยู่ไกล ซึ่งให้รางวัลผิดพฤติกรรมมาตั้งแต่ต้น
- **Move Speed ถาวรตามเลเวลอาวุธ** 5/10/15/20/25% — แกนที่หายไปทั้งดุ้น (เดินเร็ว → ชาร์จไว → ยิงถี่)
- **cast คู่**: `evenCastRadiusMult` + knock back + Super ระเบิดสองครั้งหน่วง 0.4 วิ ที่จุดเดิม
- **`IsSuper` อ่านจาก `WeaponData.tier`** แทนธงที่ไม่มีใครเปิด
- **Valor**: stun 2 วิ, ระยะ dash จาก `AbilityData.range`
- **Wind Slash** ย้ายไป Blade of the Exile แล้วถอดออก (ซ้อนกับ projectile burst)

### บั๊กที่แก้

- `isDashing` รั่วเมื่อตายกลาง dash → ขยับไม่ได้ถาวรหลัง respawn (`try/finally` สามจุด)
- dash เลี้ยงตัวเอง — dash 6 units × rate 20 ตอน Exile = 120 charge เกินหลอด 100
- เลือกตัวละครไม่ได้เลย — ไม่มีตัวไหนติ๊ก `unlockedByDefault` ทองเริ่ม 0 หาเพิ่มไม่ได้
- index การ์ดเคลื่อนเมื่อ `characters` มีช่องว่าง
- คีย์ Submit ยิงการ์ดที่โฟกัสค้าง เปลี่ยนตัวละครโดยผู้เล่นไม่รู้ตัว
- `AbilityBase` ได้ท่อ VFX (เดิมมีแต่ SFX)

## 4 · บั๊กที่รู้แล้วยังไม่แก้

**NapalmBomb วงเล็กกว่า Molotov** — `WD_NapalmBomb.radius = 0` จึงตกไปใช้ `explosionRadius` บน prefab ซึ่งเป็นค่า default 2.5 · Molotov Lv5 อยู่ที่ 3.5 → **อัปเป็น Super แล้ววงหดลง 29%**
doc comment ในหัว `NapalmBombWeapon.cs` เขียนไว้เองว่าตั้งใจให้ `radius=4.5` แต่ไม่เคยกรอกลง asset
`NapalmBombWeapon` เป็น subclass เปล่าของ `MolotovWeapon` ไม่มี logic ต่างเลย — ปัญหาอยู่ที่ข้อมูลล้วน
· **ต้องการการตัดสินใจเรื่องบาลานซ์** ว่าจะใช้ 4.5 ตาม doc หรือเลขอื่น

**`IndexOutOfRangeException` ที่ `Selectable.OnEnable`** — ยังไม่ทราบต้นเหตุ · ผู้เขียน `s_Selectables`/`s_SelectableCount` มีแค่ `OnEnable` / `OnDisable` / `ResetStaticsOnLoad` ไม่มีอันไหนที่โค้ดเราเรียก · เป็น static ระดับเกม เพี้ยนครั้งเดียวแล้วทุก Selectable ที่ enable หลังจากนั้นพังหมด ข้ามซีนด้วย
· วิธีตัด: Stop → Play ใหม่ (หายคือ static ค้างข้ามรอบ) แล้วลองปิด component `CharacterCarousel`

**ability ไม่เคยเลเวลอัป** — `AbilityBase.SetLevel` ไม่มีผู้เรียกทั้งโปรเจกต์ · Valor ค้าง 80 dmg/cd 8/range 4 · Exile ค้าง cd 60/dur 15 ตลอดรัน · ตาราง 5 เลเวลของทั้งคู่เป็นข้อมูลตาย

**`AD_Riven_BladeOfExile` เลเวล 2 แย่กว่าเลเวล 1** — cd `60→75→70→65→60` · dur `15→14→17→20→25` · ถ้า Lv1 เป็น cd 80 / dur 12 ลำดับจะเรียงสวยทั้งคู่ · ตอนนี้ยังไม่กัดเพราะข้อบน

**`StormBunnyWeapon` เข้าถึงไม่ได้** — prefab มีแต่ไม่มี WeaponData และไม่มี recipe ไหนใช้ `WD_RabbitHop` · และมันยังไม่ได้อัปเดตตาม `FireBlast` ที่แยกออกมา

**`suppressDefaultMovement` ชนกัน** — `FreezeRoutine` จบแล้วเซ็ต `false` ทับ ทำให้ `EnemyRanged` ที่ตั้งธงนี้ไว้ถาวรเริ่มเดินตามผู้เล่นหลังโดน Valor stun สร่าง

**`Char_Gunner 1` / `Char_Gunner 2` ต้องลบก่อน merge** — ไฟล์ทดสอบ carousel ที่ถูกอ้างใน `MenuScene.unity` แล้ว ทั้งสามไฟล์มี `characterName: Gunner` ซ้ำกัน ซึ่งเป็นตัวระบุบนเน็ตเวิร์กตาม CLAUDE.md ข้อ 10

## 5 · ค่าที่เพิ่งมีชีวิต / ยังไม่ได้จูน

**จังหวะยิง BunnyHop ช้าลง 2.5 เท่า** — ก่อนแก้ dash นับเป็นระยะสะสมด้วย เดินจริงแค่ 4 units ต่อครั้ง (ยิงทุก 0.67 วิ) · ตอนนี้เดินเต็ม 10 units (ยิงทุก 1.67 วิ) · `chargePerUnit: 10` ตั้งไว้ตอนที่ dash ยังป้อนตัวเอง ยังไม่ได้จูนใหม่
เทียบต้นฉบับ: 100 charge ÷ 8 ต่อ 25 units = 312.5 หน่วย Swarm ≈ **5 หน่วย Unity** → `chargePerUnit` ควรเป็นราว 20

**Move Speed ถาวรที่เพิ่งใส่** จะไปเร่งวงจรนี้กลับ ยังไม่รู้ว่าชดเชยกันพอดีไหม

**`exileProjectileRangeMult: 7`** บน `BunnyHop_Weapon.prefab` (สคริปต์ default 2) → Lv5 กระสุนบินไกล 38.5 units

**เพดานโล่ต่างจากต้นฉบับ 50 เท่า** — ต้นฉบับตันที่ 2% ของเลือดสูงสุด ของเราตันที่ `maxHealth` เต็ม และคูณ `× enemiesHit` ซึ่งต้นฉบับไม่มี

## 7 · บทเรียนวิธีทำงานจากรอบนี้

**เงียบเมื่อหาไม่เจอ = ฟีเจอร์ตายโดยไม่มีใครรู้** — รอบนี้เจอรูปแบบเดียวกันสามครั้ง
`ActivateSuper()` ที่ไม่มีใครเรียก (RabbitHop ไม่เคยระเบิดครั้งที่สองตั้งแต่ต้น) ·
`GetComponent<RectMask2D>()` ที่ดูแค่ root ทั้งที่ mask อยู่บนลูก ·
`CurrentCharge = 0f` ก่อนเช็ก weapon
· ทางแก้เดียวกันหมด: ถ้าหาไม่เจอให้ **ดัง** ไม่ใช่ข้ามเงียบ

**เลื่อนจังหวะอะไรก็ตาม ต้องไล่ทุกทางเข้า ไม่ใช่แค่ทางหลัก** — การเลื่อน player spawn คิดถึงแค่ทางเมนู → StartGame แล้วพัง `WeaponTestScene` ที่เข้าทาง `AutoHost` · เจ้าของเป็นคนเจอ ไม่ใช่การตรวจ

**`?.` กับ `??` ของ C# ไม่รู้จัก destroyed object ของ Unity** — ต้องใช้ `!=` ที่ Unity override ไว้ · เป็นกับดักที่ทั้งไฟล์อ่านแล้วดูปกติ

**อ่านสเปกต้นทางถูกกว่าการเดา** — ค้น wiki ของ LoL Swarm ครั้งเดียวเจอว่า Runic Blade กลับทิศมาตั้งแต่ต้น, cast ที่สองควร knock up (ไม่ใช่ "ฟันใหญ่ขึ้น" ที่เดาไว้ก่อนหน้า), และ Wind Slash ผูกกับ "การ dash ใดๆ" ไม่ใช่กับสกิลใดสกิลหนึ่ง

**เดาความหมายคำสั่งสั้นๆ เสียเวลากว่าถาม** — "ตัวที่ล็อก" ตีความได้ทั้ง "ตัวละครที่ยังไม่ปลดล็อก" และ "ตัวที่ล็อกตำแหน่งไว้" · รอบนี้เดาถูก แต่ถ้าผิดคือเสียงานทั้งรอบ
