## 7 · เครื่องมือ

Editor ต้อง **ปิด** ก่อนรัน batchmode — มันถือ `Temp/UnityLockfile` อยู่

```bash
U="E:/Zenity Why not/Unity/6000.7.0a2/Editor/Unity.exe"
P="E:/Zenity Why not/cloneSwarm"

"$U" -quit -batchmode -nographics -projectPath "$P" \
     -executeMethod CloneSwarm.EditorTools.P3RCharacterSceneBuilder.Build -logFile "<ABS>/b.log"
"$U" -quit -batchmode -nographics -projectPath "$P" \
     -executeMethod CloneSwarm.EditorTools.P3RScreenMigrator.MigrateFromCommandLine \
     -screen "CHARACTER" -logFile "<ABS>/m.log"
"$U" -quit -batchmode -nographics -projectPath "$P" \
     -executeMethod CloneSwarm.EditorTools.P3RScreenWirer.WireMenuScene -confirm -logFile "<ABS>/w.log"
"$U" -batchmode -projectPath "$P" \
     -executeMethod CloneSwarm.EditorTools.P3RSmokeTest.Run -logFile "<ABS>/s.log"
```

สี่ธงที่พลาดง่ายและ **พังเงียบทั้งสี่**

- `-logFile` ต้องเป็น path เต็ม · ชื่อไฟล์เปล่าจะไปอ้างกับโฟลเดอร์ที่ติดตั้ง Git Bash → Unity ออกด้วย 127 แต่ pipeline ยังรายงาน 0
- screenshot ต้องมี graphics device — `-batchmode` เฉยๆ ได้ `-nographics` ไม่ได้
- wirer ต้องมี `-confirm` ใน batchmode ไม่งั้นมัน dry-run · เคยย้าย reference 170 จุดแล้วเซฟทับซีนเพราะ batchmode ข้าม dialog
- `P3RSmokeTest.Run` ห้ามใส่ `-quit` — มันออกเองเมื่อเทสต์จบ

**คอมไพล์ตอน Editor เปิดค้าง** — ก๊อป `Library/Bee/artifacts/*.dag/Assembly-CSharp.rsp` แล้วเปลี่ยน `-out`/`-refout` ไปที่ scratch ก่อนรัน `csc.dll` · ไฟล์ `.cs` ใหม่ต้อง append เข้า rsp เอง (ขึ้นบรรทัดใหม่ก่อน — rsp ไม่มี newline ปิดท้าย)

## 8 · กับดักที่เสียเวลาที่สุด

เขียนครบ 12 ข้อไว้ใน `.claude/skills/game-ui/SKILL.md` แล้ว สามข้อที่เจ็บที่สุด

**การ์ดกดไม่ติด โดยไม่มี error อะไรเลย** — `P3RBuilderKit.NewImage` ตั้ง `raycastTarget = false` ให้ Image ทุกตัว · ทั้งกิ่งของการ์ดจึงไม่มี Graphic ตัวไหนรับ raycast · Button ที่ไม่มี Graphic รับ raycast จะไม่ได้รับคลิกเลยและไม่แจ้งอะไร
ที่หลอกกว่านั้น: ใน Inspector `Target Graphic: None` กับ `On Click () List is Empty` เป็นเรื่อง**ปกติ**ของปุ่มที่ต่อสายตอนรัน — ดูตรงนั้นแล้วสรุปไม่ได้

**แก้ builder แล้วจอไม่เปลี่ยน** — migrator สร้าง panel ซ้ำ เพราะหาลูกเฉพาะชั้นแรกใต้ Canvas แต่ panel ถูกย้ายลงใต้ `P3R_Hub` แล้ว · ตัวเก่าที่ถือข้อมูลจริงยังอยู่และเป็นตัวที่เกมใช้ · ไม่มี error สักบรรทัด

**`TabBar.SetTabVisible` ไม่เห็นผล** — `tabs[].button` เป็น null ทั้งสี่ และปุ่มที่เห็นบนจอเป็นสำเนาของแต่ละ panel คนละตัวกัน · ต้องผ่าน `P3RTabStrip` ซึ่งต้องแปะบน `TabBar` ไม่ใช่บนปุ่ม (component ที่ปิด GameObject ของตัวเองจะหยุดรับ event)

- prefab ที่ networked ต้องเข้า `Assets/DefaultNetworkPrefabs.asset`
- ID ตัวละครบนเน็ตเวิร์กคือ `CharacterData.characterName` (string) ห้ามใช้ index
- สีผู้เล่นจาก `PlayerSlotRegistry.GetSlot()` ห้ามใช้ `clientId % 4`
- input ของ ability จาก `AbilityInputActions.inputactions` ห้าม poll `Keyboard.current`
