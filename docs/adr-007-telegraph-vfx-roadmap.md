### ข้อ 2 — คำอธิบายเดิมผิด แก้แล้ว 2026-08-13

เดิมเขียนว่า `_Ring*` `_Edge*` `_BaseAlpha` "ตายแล้ว" และสั่งให้ลบออกจาก material · **ไม่จริง**

ตรวจจากไฟล์จริงแล้ว `TelegraphUniversal.shadergraph` ประกาศ property ครบทั้ง 17 ตัว
และ `TelegraphZone.cs:604-614` เขียนค่าให้ทุกตัวผ่าน `MaterialPropertyBlock` จริง
**ไม่มีตัวไหนตาย · ลบคือทำภาพพัง**

ปัญหาตัวจริงคนละเรื่อง — **ค่าที่เซฟไว้ใน `.mat` ไม่เคยมีผล** เพราะ MPB เขียนทับทุกครั้ง
designer เปิด material inspector ไปหมุนค่า `_RingSpeed` แล้วไม่มีอะไรเกิดขึ้น และไม่มีอะไรบอก
material inspector จึงเป็นตัวล่อ ไม่ใช่ที่ตั้งค่า

**นี่เป็นการตัดสินใจ ไม่ใช่งานลบ** — ต้องเลือกว่าใครเป็นเจ้าของค่า
· ให้ material ชนะ = ถอด `SetIfPresent` ของ property ที่ designer ควรปรับเองออก
· ให้ prefab ชนะ = เก็บ MPB ไว้ แล้วทำให้ material inspector บอกได้ว่าค่าตรงนี้ถูกทับ
ยังไม่ตัดสิน · ไม่บล็อกงานรอบนี้

### ข้อ 8 แย่ลงจริงตามที่ ADR-005 เตือนไว้

ADR-005 เขียนไว้ว่างานเพิ่มสูตรลง shader จะทำให้หนี้ข้อนี้โตขึ้น · **เกิดขึ้นแล้ว**

## 3 · ภาษาภาพ — กติกาที่ต้องไม่แตะ

**สีของ telegraph บอกว่า *ต้องทำอะไรถึงรอด*** — ColorMatch > override ต่อท่า > Gaze > Stack > Chase
เรียงตาม "ทำตามสัญชาตญาณปกติแล้วตายแค่ไหน" · `WarnIfMultipleColorCategories()` เตือนตอนชนกัน
เพราะสีบอกได้ทีละอย่าง

**ธาตุ (ไฟ/น้ำแข็ง/สายฟ้า) บอกว่า *มันคืออะไร*** — ให้ไปอยู่ที่ VFX กับอนุภาค **ห้ามมาแย่งสี telegraph**

> ถ้าให้ธาตุชนะ ท่า Gaze ของบอสไฟจะเป็นสีส้มแทนสีม่วง แล้วผู้เล่นจะตายโดยไม่รู้ว่าต้องหันหลัง
> — สัญญาณที่ตัดสินเป็นตายถูกกลบด้วยสัญญาณที่บอกแค่รสชาติ

ถ้าอยากให้ธาตุมีสีจริงๆ ต้องเป็น**มิติที่สอง** เช่นสีขอบ ซึ่ง**แยก gate ไว้แล้ว**
(`overrideTelegraphOutlineColor`, 2026-08-13) · ต้องเทสต์ด้วยตาว่าสองสีในวงเดียวยังแยกออกตอนจอรก

**ขนาดที่ต่างตามความยาก ไม่ใช่ VFX ตัวใหม่** — `PlayByName` รับ `scale` อยู่แล้ว
ทำเป็น entry แยกจะได้ 45 ตัวแทนที่จะเป็น 9–15

## 4 · งานที่ค้าง เรียงตามที่ควรทำ

### รอบหน้า — VFXAsset (ADR-006)

Action Items 1–7 ใน ADR-006 · จุดที่พลาดง่ายสองข้อ

- id **ห้ามใช้ `GetInstanceID()`** ไม่ตรงกันข้ามเครื่อง — ใช้ index ใน `VFXDatabase`
- script migrate **ต้อง `LogError` เมื่อหา key ไม่เจอ** — นี่จะเป็นครั้งแรกที่รู้ว่ามี key พิมพ์ผิด
  ค้างอยู่ในโปรเจกต์กี่ตัว ซึ่งตอนนี้ไม่มีใครรู้

**ทำพร้อมกัน** — เพิ่มพารามิเตอร์สีใน `PlayByName` ไม่งั้นพอบอส 3 ธาตุมาจะเริ่มมี
`Detonate_Fire_Purple` แยกจาก `Detonate_Fire_Blue` แล้ว asset ระเบิดเป็นทวีคูณ

### หนี้ราคาถูก ทำแทรกได้

- ~~ลบ `_Ring*` `_Edge*` `_BaseAlpha` ที่ตายแล้ว~~ **ยกเลิก** — ไม่มีตัวไหนตาย ดู §2 ข้อ 2
- คอมเมนต์โยงสูตรกราฟ ↔ `IsInXxx` (บรรเทาหนี้ข้อ 8)
- รวมชื่อ shader property เป็น `static readonly int` + validator (หนี้ข้อ 1 ฝั่งที่ยังไม่ทำ)
- EditMode test ของ `IsInCircle/IsInLine/IsInDonut/IsInCone` — คณิตล้วน ไม่ต้องมี scene (หนี้ข้อ 7)
  · โค้ดเกมอยู่ใน `Assembly-CSharp` และ**ไม่มี asmdef** · asmdef อ้าง predefined assembly ไม่ได้
  ต้องวางเทสต์ในโฟลเดอร์ `Editor` แบบไม่มี asmdef ไม่งั้นเทสต์จะมองไม่เห็นโค้ดเกม

### งาน Editor ที่โค้ดทำแทนไม่ได้

**ผูก `rollName` ให้ action** — คุ้มที่สุดในลิสต์และไม่ต้องเขียนโค้ดเลย
ระบบ roll เสร็จตั้งแต่ `f5591838` แต่ยังไม่มี action ไหนผูกชื่อ **งานทั้งก้อนจึงยังไม่มีผลกับเกม**

· สร้าง asset ของ `ConeAoEAction` / `LimitCutAction` · ตั้ง `detonateVfxKey` ต่อ action

### ยังไม่เคยเห็นในเกม

งาน telegraph หลังภาพที่เจ้าของส่งมา compile ผ่านหมดแต่ยังไม่ได้กด Play
— ขนาดรูโดนัท ขอบใน `visualYOffset` และการปิดเงา

## 5 · สิ่งที่ลองแล้วไม่ได้ผล — อย่าเสนอซ้ำ

| ลองอะไร | ทำไมไม่ได้ผล |
|---|---|
| วางจานสีปลอดภัยทับแทนการเจาะรูโดนัท | วัตถุโปร่งแสงวาดทับกันได้แต่**ลบของข้างล่างไม่ได้** ฟ้าจางบนแดงยังอ่านว่าแดง |
| ใส่ prefab ตรงๆ แทน VFX key | ส่งข้ามเน็ตเวิร์กไม่ได้ (zone ไม่รู้ว่า action ไหนสร้างมัน) · เสีย pool · ผิดกฎข้อ 2 |
| Scene Depth intersection สำหรับ Cross | Unity เก็บ depth **หลัง opaque ก่อน transparent** ตรวจ intersection ระหว่าง transparent สองชิ้นไม่ได้ |
| Quad + SDF ทุกทรง | ADR-004 — object space ของ Quad อยู่บนระนาบ XY, `Z = 0` สูตรระยะขอบพัง |

## 6 · บทเรียนวิธีทำงาน

**`unity-check` ยืนยันได้แค่ว่าคอมไพล์ผ่าน** ไม่ได้บอกว่าภาพตรงกับ hit test
· ทุกอย่างในเซสชัน 2026-08-12/13 ผ่าน compile หมดแต่บั๊กที่เจอทั้งวันไม่มีตัวไหนที่ compiler จับได้

**แก้ `.shadergraph` ผ่าน batchmode ได้จริง** — reflection บน internal API · **ตรวจ edge จากไฟล์จริง
ไม่เชื่อ log** · สคริปต์ผ่าตัดต้องลบทิ้งหลังใช้ ไม่งั้นรันซ้ำจะได้โหนดซ้อน · สำรองก่อนเสมอ

**ปิด Unity ก่อนรัน batchmode** — เจอปัญหานี้ 4 รอบในวันเดียว · เช็คด้วย `unity-check.ps1 -DryRun`

**อย่าเขียนไฟล์ที่มี escape character ผ่านสคริปต์แปลงหลายชั้น** — `\n` ใน tooltip กลายเป็น
ขึ้นบรรทัดจริง ทำให้ string literal ขาดแล้วพังต่อกันสิบบรรทัด · เคสแบบนี้ให้แก้ตรงๆ
