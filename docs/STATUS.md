## 🔴 ค้างที่ตัวคุณ — ไม่มีใครทำแทนได้

เรียงตามความสำคัญ ไม่ใช่ตามลำดับเวลา

### 1. เล่นเทสต์ Round 7-8 ← เหลืออย่างเดียวที่ค้างจริง

Round 1-6 เทสต์ผ่านหมดแล้ว **แต่ Round 7-8 ยังไม่มีใครเห็นด้วยตา** — compile ผ่าน
แต่บทเรียนของโปรเจกต์นี้คือบั๊กหนักทุกตัว compile จับไม่ได้

| ต้องดู | ทำไมสำคัญ |
|---|---|
| **2 เครื่อง**: host กด ESC → **ศัตรูต้องเดินต่อ** · client เล่นได้ · host ขยับ/ยิงไม่ได้ | ของใหม่ทั้งหมดใน Round 8 · เป็นทางแก้ที่คุณเลือกเอง |
| **solo**: กด ESC → หยุดหมดเหมือนเดิม | กันแก้เกิน |
| เลขดาเมจขึ้นบน**จอ client** ด้วย · คริตดูต่างชัด | ปลดล็อกเทสต์ที่ค้างมาตั้งแต่ Round 1 |
| Crate บนจอ client | ยืนยันว่าทฤษฎีจังหวะ spawn ถูก |
| ปรับสี/ขนาดเลขใน Inspector ของ `NetworkedVFXPool` | ของที่คุณขอ |

⚠️ **หลัง pull ครั้งแรก** — `FloatingDamageText.cs`/`FloatingDamageTextPool.cs` ถูกลบ
(ย้ายเข้า `NetworkedVFXPool.cs`) ถ้ามี GameObject ไหนเคยแปะ component เก่าจะขึ้น
**Missing Script** ลบทิ้งได้เลย ระบบใหม่ไม่ต้องตั้งค่าอะไรในซีน

### 3. `NetworkAnimator` บนบอส — เลื่อนไว้เอง

`Purple 1.prefab` มี `NetworkAnimator` ที่ไม่ได้ assign Animator → **error 1 อันต่อเฟรม**
ตลอดที่บอสมีชีวิต (590 อันในรอบที่เล่น) คุณบอกว่ายังเป็น mock-up art เลยพักไว้

พอ art นิ่งแล้วเลือก: ถอด component ทิ้ง (มันไม่ได้ sync อะไรอยู่แล้ว) หรือ assign + ตั้ง `ParameterEntries`

### 4. ~~ติ๊ก Emission บน material ของ orb~~  ✅ **ไม่ต้องทำแล้ว**

เทสต์แล้ว orb ยังเรืองแสงปกติ — material มี Emission ติ๊กไว้อยู่แล้ว ปิดเรื่องนี้ได้

### 5. เทสต์ VFX pool report

เข้าเกม → เล่นถึงช่วงหนักสุด (wave 30 + บอส) → **กด F1** ดูส่วน VFX Pool → กด **Log VFX Report**
เอาคอลัมน์ "ควรตั้ง" ไปใส่ `poolSize` ใน `VFXDatabase`

⚠️ เลขที่ได้จาก solo **ต่ำกว่าความจริง** — ถ้าจะ bake ลง asset ควรวัดตอน co-op

### 6. ตัดสินใจ 2 เรื่องที่บล็อกงานใหญ่

| เรื่อง | ต้องตอบเมื่อไร |
|---|---|
| **Hit RPC throttling** — batch / throttle ต่อ enemy / ให้คนยิง predict | **ก่อนเริ่ม Stage 1** เพราะแตะ damage path เดียวกัน ตอบช้า = ทำซ้ำ |
| **โลกในเกมหลัง host migrate** — สร้างใหม่ (แนะนำ) หรือเก็บทั้งหมด | ตอน Stage 4 ยังไม่รีบ |

### ผลการทดลองวัดเพดาน Antigravity

ขนาดต่อรอบ (tasks/ไฟล์): **6/10 → 7/6 → 10/12 → 9/8 → 14/14 → 10/8 → 11/13**

**ไม่เจอเพดานเรื่องจำนวนเลย** — 14 tasks ก็ยังทำครบ ขอบเขตตรง ไม่มีไฟล์เกินสักรอบ
ข้อจำกัดจริงคือ **ของที่เหลือให้ทำ** ไม่ใช่ความสามารถของ coder

| อาการ | เกิดกี่ครั้ง | รายละเอียด |
|---|---|---|
| **scope creep** | 3 | Round 3 เปลี่ยน private field เป็น property · Round 4 เติม `else Destroy()` · Round 5+6 เปิด shader keyword บน `sharedMaterial` (= เขียนทับ asset) |
| **compile ไม่ผ่าน** | 1 | Round 4 — และเป็น**ความผิดของแผน** ไม่ใช่ของ coder |
| **หยุดแล้วถามตามกติกา** | 1 | Round 8 T5 — เจอ ability กระจาย 6 ไฟล์ เกินเพดาน 3 ที่แผนตั้ง **หยุดจริง** เขียนรายชื่อไว้ใต้ `## Questions` |

**scope creep หายไปใน Round 7-8** หลังเขียนกฎให้ตรงรูปแบบที่มันทำ (ไม่ใช่แค่ "ห้ามเกินขอบเขต"
แต่ระบุว่า "ห้ามเติมโค้ดกันไว้ก่อนที่ไม่มีใครขอ") และ Round 8 เป็นครั้งแรกที่กติกา
**"ถ้าติดให้หยุดแล้วถาม" ทำงานตามที่ออกแบบ** — บทเรียนคือกฎต้องระบุ*รูปแบบ*ของความผิด ไม่ใช่แค่ห้ามลอยๆ

**นอก Round** (ทำตรงไม่ผ่านลูป): VFX pool report + DevTools F1 · ตั้งค่า pool จากเลขจริง ·
แก้ path scene ผิดใน `CLAUDE.md` · บั๊ก Crate · DevTools ปุ่ม/ฟอนต์ · รวม damage text เข้า VFX pool ·

## 🗺 แผนระยะยาว — ประมาณ ไม่ใช่สัญญา

เป้าหมายปลายทาง: **client reconnect** และ **host migration**

| กอง | ประมาณ | หมายเหตุ |
|---|---|---|
| เศษ audit ที่ค้าง (P1/P3 + config) | ~2–3 Round | ทำเมื่อไรก็ได้ ไม่บล็อกใคร |
| Stage 0.1 buff ไม่ทำงานสำหรับ client | ~1 Round | บั๊กที่คนเล่นเจอจริง |
| **Stage 1 server ถือ player state** | **~5 Round** | **รากของทุกอย่าง** · ก้อนใหญ่สุด · ปิด audit ค้างหลายข้อในตัว |
| Stage 2 reconnect | ~1–2 Round | ได้ฟีเจอร์แรก |
| Stage 3 run snapshot | ~1–2 Round | |
| Stage 4 host migration | ~2–3 Round | ได้ฟีเจอร์ที่สอง |

**รวม ~12–16 Round** โดย Stage 1 กินเกือบครึ่ง

⚠️ ตัวเลขนี้เชื่อได้แค่หยาบๆ — Round 3 เป็นต้นไปยังไม่มีใครเขียน และสองรอบที่ผ่านมา

**เศษ audit ที่ค้างในตารางนี้ถูกเก็บไปเกือบหมดแล้ว** เหลือของที่ต้องแก้ `.prefab`/`.asset` เป็นหลัก

## 💡 บทเรียนที่แลกมาแล้ว — อย่าลืม

- **compile ผ่านไม่ได้แปลว่าถูก** — บั๊กที่หนักที่สุดทุกตัวจนถึงตอนนี้ compile จับไม่ได้เลยสักตัว
  โปรเจกต์ไม่มี automated test การเล่นเทสต์คือตาข่ายเดียวที่มี
- **เล่นเป็น host = ไม่ได้เทสต์** ครึ่งหนึ่งของบั๊กที่เจอโผล่เฉพาะบน client
- **แก้บั๊กเสร็จต้อง grep หาไฟล์รูปแบบเดียวกันก่อนปิดงาน** — โปรเจกต์นี้มีไฟล์โครงเหมือนกันเป็นตระกูล
  และเคยแก้ตกพี่น้องมาแล้ว **6 ครั้ง** (ครั้งล่าสุดคือ `MiniBossBarEntry` ที่แผน Round 1 เขียนเตือน
  เรื่องนี้ไว้เองแล้วยังตกอยู่ดี)
- **audit ที่อ่านแต่โค้ดมองไม่เห็นบั๊กใน `.prefab`** — สองบั๊กจากการเล่นจริงล่าสุดไม่มีตัวไหนอยู่ในโค้ด
