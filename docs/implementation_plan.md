### ตรวจแล้วก่อนเขียนแผน

- `SaveManager.Data` โหลด lazy — `if (_data == null) Load();` (`:41`) แปลว่าแทรกท้าย `Load()`
  ได้ผลก่อนที่ UI ไหนจะอ่านทอง
- `ResetProfile()` (`:162`) เซ็ต `_data = SaveData.CreateNew()` **ไม่ผ่าน `Load()`** →
  ถ้าไม่แทรกตรงนี้ด้วย กดปุ่ม Reset ในร้านทั้งที่เปิด override อยู่จะได้ทอง 0 แล้วงงว่าทำไม
- `MetaProgression.Gold => SaveManager.Data.gold` (`:22`) อ่านผ่าน `Data` ตัวเดียว ไม่มีทางลัดอื่น
- `SaveData` ไม่มี `[CreateAssetMenu]` ที่ไหน — เมนู `LoL Swarm/` เป็น prefix ที่ `MapData` ใช้อยู่แล้ว

### [x] T81 · SaveManager: อ่าน override ตอนโหลดโปรไฟล์

- เพิ่มเมธอด private ใต้ `Load()`:
```csharp
/// <summary>
/// ทับค่าจาก Assets/Resources/DevProfileOverride.asset — Editor เท่านั้น
/// ไม่เรียก MarkDirty() โดยตั้งใจ: ค่านี้ไม่ควรถูกเขียนลงดิสก์เพราะแค่ตั้งค่ามัน
/// </summary>
static void ApplyDevOverride()
{
#if UNITY_EDITOR
    if (_data == null) return;

    var ov = Resources.Load<DevProfileOverride>("DevProfileOverride");
    if (ov == null || !ov.applyOnPlay) return;

    _data.gold = ov.gold;
    if (ov.alsoSetLifetimeGold) _data.lifetimeGold = ov.gold;

    Debug.Log($"[Save] DevProfileOverride ทำงาน — ตั้งทองเป็น {ov.gold:N0}");
#endif
}
```
- เรียก `ApplyDevOverride();` **สองที่**:
  1. ใน `Load()` — วางไว้**ก่อน** `_dirty = false;` (บรรทัด ~71)
  2. ใน `ResetProfile()` — วางไว้**ระหว่าง** `_data = SaveData.CreateNew();` กับ `Save();`
     ไม่งั้นกดปุ่ม Reset ในร้านทั้งที่เปิด override อยู่จะได้ทอง 0
- **ห้าม**เปลี่ยนลำดับใน `Load()` นอกจากแทรกบรรทัดเดียวนี้ — `Migrate()` ต้องทำงานก่อนเสมอ
