## Project Rules (ห้ามละเมิด)

1. **Server-authoritative** — client เขียน state ผ่าน ServerRpc เท่านั้น
2. prefab ที่ spawn ผ่าน NGO ต้องอยู่ใน `DefaultNetworkPrefabs.asset` — **งานมือของผู้ใช้**
3. **VFX**: `NetworkedVFXPool.Instance.PlayByName(string key, pos, ...)`
4. **SFX**: `SoundManager.Instance.PlaySfx*` เท่านั้น
5. static event: subscribe `OnEnable` / unsubscribe `OnDisable` เสมอ
6. ห้ามเขียน `Time.timeScale` ตรงๆ — ผ่าน `GamePause`
