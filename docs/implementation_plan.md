## Fix Round 2

### [ ] F2 · `public` เกินบนเมธอดที่รับ type ที่ private
- **File**: `Assets/Script/Data/Network/MenuManager.cs` — บรรทัด **160**
- **Error**: `CS0051: Inconsistent accessibility: parameter type 'MenuManager.MenuMode' is less
  accessible than method 'MenuManager.OnPlayClicked(MenuManager.MenuMode)'`
- **Root cause**: บรรทัด 80 ประกาศ `private enum MenuMode` แต่บรรทัด 160 ทำ
  `public void OnPlayClicked(MenuMode mode)` — C# ไม่ยอมให้เมธอด public รับ type ที่ private
- **ตรวจแล้วว่าใครเรียกบ้าง**: มีแค่บรรทัด 166 (`OnPlaySoloClicked`) และ 168 (`OnOnlineClicked`)
  ทั้งคู่เป็น private และอยู่ในคลาสเดียวกัน · ปุ่มผูกผ่าน `AddListener(...)` ในโค้ด
  ไม่ได้ผูกจาก Inspector → **ไม่มีใครนอกคลาสต้องการ `public` ตัวนี้**
- **Fix**: บรรทัด 160 ลบคำว่า `public` ออกคำเดียว ให้เป็น
  `void OnPlayClicked(MenuMode mode)`
- **ห้าม**เปลี่ยน `enum MenuMode` เป็น public — กระทบกว้างกว่าโดยไม่จำเป็น
- **ห้าม**แก้อย่างอื่นในไฟล์นี้ ข้ออื่นทั้ง 13 ข้อคอมไพล์ผ่านแล้ว
