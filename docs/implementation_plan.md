## Project Rules (ห้ามละเมิด)

1. **Server-authoritative** — client ห้ามเขียน gameplay state ตรงๆ · ServerRpc → `NetworkVariable`
2. prefab ที่ spawn ผ่าน NGO ต้องอยู่ใน `Assets/DefaultNetworkPrefabs.asset` — **งานมือของผู้ใช้**
3. **VFX**: `NetworkedVFXPool.Instance.PlayByName(string key, pos, ...)` — ห้าม `Instantiate` ตรงๆ
4. **SFX**: `SoundManager.Instance.PlaySfx*` เท่านั้น
5. **static event**: subscribe `OnEnable` / unsubscribe `OnDisable` เสมอ
6. **boss spawn event** ต้องยิงที่ **บนสุด** ของ `OnNetworkSpawn` ก่อน `IsServer` early-return
7. ห้ามเขียน `Time.timeScale` ตรงๆ — ผ่าน `GamePause`

```csharp
public class RollContext
{
    public RollContext(int seed, RollDefinition[] defs);
    public int  Seed { get; }
    /// สุ่มค่าใหม่ให้ roll ชื่อนี้แล้วคืนค่า · เคารพ excludePrevious

}
```
