## Context

งานกลล้วน 5 ไฟล์ + 1 call site ไม่มีการตัดสินใจเชิงออกแบบ

- **บั๊กจริงที่เจอตอนเล่น** — `MissingReferenceException: 'HunterUltimate' has been destroyed but you
  are still trying to access it` ที่ `Behaviour.set_enabled`
  ต้นตอ: `AbilityBase.cs:49-61` subscribe static event `SceneManager.activeSceneChanged` ใน `Awake`
  แล้ว unsubscribe ใน `OnDestroy` — ตอนออกจาก gameplay scene event ยิงพร้อมๆ กับที่ object ถูก destroy
  Unity ไม่การันตีลำดับ → delegate ยังถือ component ที่ตายแล้ว → `enabled = ...` ระเบิด
  **กระทบทุก ability ที่สืบทอด `AbilityBase` ไม่ใช่แค่ HunterUltimate**
- `Enemy.cs:20` `public static readonly List<Enemy> ActiveEnemies` — `.Contains(this)` ที่ `:84` เป็น O(n)
  ทุกครั้งที่ enemy spawn และ `.Remove(this)` ที่ `:109`/`:114` ก็ O(n)
- `EnemySpawner.cs:54` `InvokeRepeating(nameof(SpawnEnemy), 0.5f, spawnRate)` — string-based
- `GameTimeline.cs:113` `Mathf.FloorToInt(t) % 2 == 0` — เงื่อนไขนี้เป็นจริง**ทุกเฟรมตลอดวินาทีคู่**
  → `CheckLoseCondition()` (ซึ่งวน `ConnectedClientsList`) รัน ~60-120 ครั้ง แทนที่จะเป็น 1
- `NetworkedVFXPool.cs:398` และ `:555` `go.transform.SetParent(null)` ตอนคืน pool
  → object ไปลอยที่ scene root แทนที่จะอยู่ใต้ pool

- [x] T3: เปลี่ยน `InvokeRepeating` เป็น Coroutine
  - File: `Assets/Script/EnemySpawner.cs` (MODIFY)

    ```csharp
    private Coroutine _spawnLoop;
    ```

  - `OnNetworkDespawn` (บรรทัด 39-42) เดิม `CancelInvoke(nameof(SpawnEnemy));` → เปลี่ยนเป็น `StopSpawning();`
  - `StartSpawning` บรรทัด 53-54 เดิม:

    เปลี่ยนเป็น:

  - `StopSpawning` บรรทัด 58-62 เดิม `CancelInvoke(nameof(SpawnEnemy));` → เปลี่ยนเป็น:
    ```csharp
    if (_spawnLoop != null) { StopCoroutine(_spawnLoop); _spawnLoop = null; }
    ```
  - เพิ่มเมธอดใหม่ (วางใต้ `StopSpawning`):
    ```csharp
    /// <summary>แทน InvokeRepeating — ยิงครั้งแรกหลัง 0.5s แล้วทุก rate วินาที (timing เดิมเป๊ะ)</summary>
    IEnumerator SpawnLoop(float rate)
    {
        yield return new WaitForSeconds(0.5f);

        var wait = new WaitForSeconds(rate);   // cache กัน GC alloc ทุกรอบ
        while (true)
        {
            SpawnEnemy();
            yield return wait;
        }
    }
    ```
  - ต้องมี `using System.Collections;` ที่หัวไฟล์ — **ถ้ายังไม่มีให้เพิ่ม**
  - Expected: ไม่มี `InvokeRepeating` / `CancelInvoke` เหลือในไฟล์นี้แล้ว
    timing เหมือนเดิม (delay 0.5s แรก แล้วทุก `rate` วินาที)

    เปลี่ยนเป็น:

    ```csharp
    // Lose Check (all PlayerObjects null = all dead) — ทุก 2 วิ

    if (t > 3f)
    {
        _loseCheckTimer += Time.deltaTime;
        if (_loseCheckTimer >= 2f)
        {
            _loseCheckTimer = 0f;
            CheckLoseCondition();
        }
    }
    ```

- [x] T5: คืน VFX เข้า pool โดยไม่ปล่อยลอยที่ scene root
  - File: `Assets/Script/VFX/NetworkedVFXPool.cs` (MODIFY)
  - **2 จุด** บรรทัด 398 และ 555 เดิมเหมือนกัน:
    ```csharp
    go.transform.SetParent(null);
    ```
    เปลี่ยนทั้งสองจุดเป็น:
    ```csharp
    go.transform.SetParent(transform, false);
    ```
  - Why: `transform` คือตัว pool เอง (singleton) — object ที่คืนแล้วอยู่ใต้ pool ไม่ลอยที่ scene root
    ใช้ `false` ให้ตรงกับ call site อื่นในไฟล์นี้ (`SetParent(parent, false)`) และไม่ต้องคำนวณ world transform ใหม่
  - Expected: ไม่มี `SetParent(null)` เหลือในไฟล์นี้แล้ว
