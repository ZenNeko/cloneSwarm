### A2. Pause  *(Round 2)*

- [x] ✅ client กด ESC → **host เล่นต่อได้ปกติ**
- [ ] ❌ **host กด ESC → ศัตรูหยุดทั้งเกม**

> **ไม่ใช่บั๊กจาก Round 2** — host คือ server ศัตรูทั้งหมดเดินด้วย `Update()` บนเครื่อง host
> พอ `Time.timeScale = 0` ที่ host ตัว simulation ทั้งเกมก็หยุด โค้ดก่อน Round 2 ก็เป็นแบบนี้
> คอมเมนต์ [PauseMenuUI.cs:23](../Assets/Script/UI/PauseMenuUI.cs:23) ที่ว่า *"หยุด local-only"*
> **จริงเฉพาะฝั่ง client** ไม่เคยมีใครจับได้เพราะไม่เคยเทสต์ 2 เครื่องพร้อมกัน
>
> **ต้องเลือกทางแก้ก่อนลงมือ**
> 1. ห้าม host pause ตอน multiplayer — เปิดเมนูได้ เกมเดินต่อ
> 2. pause เฉพาะ input/UI ของ host ไม่แตะ `timeScale`
> 3. ยอมรับว่าเป็น pause ทั้งเกม แล้วแจ้ง client ว่า "host หยุดเกม"
