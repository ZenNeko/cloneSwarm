## 🔴 A — ต้องเปิด 2 instance (host + client)

**นี่คือกลุ่มที่สำคัญที่สุดทั้งลิสต์** เพราะบั๊กหลักของ Round 1 **โผล่เฉพาะบนจอ client**
และเหตุผลที่มันรอดมานานคือที่ผ่านมาเล่นเป็น host ตลอด — **เล่นเป็น host เท่ากับไม่ได้เทสต์**

### A1. หลอดเลือดบอสบนจอ client  *(Round 1 · N1)*

ดูจาก **จอ client** เท่านั้น (จอ host ถูกอยู่แล้วทั้งก่อนและหลังแก้ ไม่ได้บอกอะไร)

- [ ] สู้ **mini-boss** → หลอดเลือดลดลงเรื่อยๆ ตามที่ตี
      **อาการเดิม**: หลอดเต็มค้าง แล้วเริ่มขยับตอนใกล้ตาย
- [ ] ตัวเลขเป็น `เลือดปัจจุบัน / เลือดที่สเกลแล้ว` เช่น `90 / 150`
      **อาการเดิม**: `150 / 30`
- [ ] ⚠️ ดู **ทั้งสองหลอด** — หลอดลอยเหนือหัวบอส **และ** แถบใน HUD ด้านบน
      ต้องตรงกันทั้งคู่ (แถบใน HUD เป็นตัวที่แผน Round 1 ตกไป ผมเจอตอน verify)
- [ ] **Elite ที่มี Shield** → หลอดต้องรวม shield HP ถูกต้องบนจอ client
- [ ] **Main Boss** ตอนนาที 15 → หลอด + เส้นแบ่ง phase ถูกบนจอ client

### A2. Pause เป็นเรื่องของตัวเองเท่านั้น  *(Round 2)*

- [ ] host กด **ESC** → **client ต้องเล่นต่อได้ปกติ** ศัตรูยังเดิน ยิงได้
- [ ] สลับกัน — client กด ESC → host ต้องไม่หยุด

### A3. ของที่รอบก่อนแก้ไว้ ยังไม่พัง

- [ ] เก็บ EXP orb / Healing orb บนจอ client → ได้ผลถูกต้อง ไม่ได้สองเท่า  *(Round 1 · N2)*
- [ ] ยิงจนคริตบนจอ client → เห็น **CritHitEffect** (คนละแบบกับ hit ปกติ)  *(Round 3 · T1-T2)*

## 🟠 B — ดูตลอดเวลาที่เล่น (Round 5+6 — เสี่ยงสุดในกลุ่ม solo)

Round 5+6 แตะ **material ของทุกอย่างที่มีสีในเกม** เปลี่ยนจาก clone material
มาเป็น `MaterialPropertyBlock` → **ถ้า shader ไม่รองรับ property ที่ส่ง สีจะไม่ขึ้นเลย**

**ไม่ต้องทำเป็นข้อๆ — แค่เล่นแล้วสังเกตว่ามีอะไรสีเพี้ยนไหม** ถ้าเจอให้จดว่าอะไร

- [ ] **EXP orb เรืองแสง** เหมือนเดิม ← ข้อที่มีโอกาสพังสูงสุด
      **ถ้าสีถูกแต่ไม่ glow** = ต้องติ๊ก **Emission** บน material ของ orb ใน Inspector ครั้งเดียว
      (`_EMISSION` เป็น shader keyword ที่ property block เปิดให้ไม่ได้ ผมจงใจไม่ไปแก้ asset)
- [ ] **Healing orb เขียว** · **Magnet orb ม่วงแดง** สีเหมือนเดิม
- [ ] ศัตรูโดน **freeze → เป็นสีฟ้าน้ำแข็ง** แล้วกลับเป็นสีปกติตอนหมดฤทธิ์
- [ ] **FloorHazard** (พื้นอันตรายของบอส) กระพริบแดงเหมือนเดิม
- [ ] **BossTether** (เส้นเชื่อมผู้เล่น) สีเหมือนเดิม
- [ ] ⚠️ **ไม่มีอะไรกลายเป็นสีชมพู/ม่วงสด** — นั่นคืออาการ material หาย

## 🟡 C — เคสเจาะจง เล่นคนเดียวได้

### C1. กด ESC แล้วต้องไม่ค้าง  *(Round 2 · N5)*

**บั๊กเดิมคือกดแล้วเกมค้างถาวร ต้องโหลดฉากใหม่**

- [ ] เล่นจนขึ้น **card UI ตอนเลเวลอัพ** → **กด ESC** → เมนู pause ขึ้นซ้อนบน card
      → กด **Resume** → **ต้องกลับไปเห็น card และเลือกได้** เกมต้องไม่ค้าง
- [ ] **Orb Phase** (เก็บ orb ที่ทำให้ทุกคนได้การ์ด) → กด ESC ซ้อนแบบเดียวกัน → Resume ได้
- [ ] จบเกม (แพ้หรือชนะ) → **กด ESC แล้ว Resume** → **โลกต้องไม่เดินต่อ**
      ศัตรูต้องไม่ขยับหลังจอผลขึ้น
- [ ] Quit to menu → **เริ่มเกมใหม่** → เกมเดินปกติทันที ไม่ค้าง
- [ ] DevTools (F1) ตั้ง **slow-mo ×0.5** → กด ESC → Resume → **slow-mo ต้องยังอยู่**

### C2. FlowField — client ต้องไม่ bake  *(Round 2 · N6)*

**ถ้าพลาด อาการคือศัตรูยืนนิ่งทั้งแมพ เห็นทันทีที่เข้าเกม**

- [ ] เข้าเกมเป็น **host** → Console ขึ้น `[FlowField] Baked 100×100 grid — N blocked cells` **หนึ่งครั้ง**
- [ ] **ศัตรูเดินเข้าหาผู้เล่นปกติ** ← ถ้ายืนนิ่งแปลว่า array ไม่ถูกสร้าง
- [ ] จอ **client ต้องไม่มีบรรทัด `[FlowField] Baked` เลย** แต่ศัตรูยังขยับปกติบนจอ client
- [ ] Quit → เข้าเกมใหม่ → ขึ้น `Baked` อีกครั้ง และศัตรูเดินได้

### C3. บอส  *(Round 3 · Round 4)*

- [ ] ⚠️ **ฆ่าบอสตอนวงเตือน AoE กำลังนับถอยหลัง** → **วงต้องหายทันที ไม่ระเบิด ไม่กินดาเมจ**
      **อาการเดิม**: ระเบิดตามปกติทั้งที่บอสตายไปแล้ว  *(Round 4)*
- [ ] **ฆ่าบอสตอน Tether กำลังทำงาน** → เส้นต้องหายทันที ไม่ค้างอีก 6 วินาทีแล้วลงโทษ  *(Round 4)*
- [ ] **สู้บอสจนจบแบบปกติ** (ปล่อยให้ท่าจบเอง) → **ทุกอย่างต้องเหมือนเดิม**
      วงเตือนต้องระเบิดตามปกติตอนบอสยังไม่ตาย ← ข้อนี้คือกันไม่ให้ Round 4 แก้เกินไป
- [ ] ⚠️ DevTools → **Spawn Main Boss → ฆ่า → ชนะ** · **spawn ใหม่อีกตัว → ฆ่า → ต้องชนะได้อีก**
      **ถ้ารอบสองไม่มีอะไรเกิดขึ้น = flag ไม่ถูกรีเซ็ต**  *(Round 3 · T3)*

### C4. Objective  *(Round 3 · T4-T5)*

- [ ] รับ quest **Survive** → **เดินออกจากโซนแล้วทิ้งไว้** → objective ต้อง **หมดเวลาแล้วหายไปเอง**
      และศัตรูกลับมา spawn อัตราปกติ (ไม่ค้าง boost)
      **อาการเดิม**: ค้างตลอดเกม กินสล็อต + บูสต์ spawn ไม่มีวันจบ
- [ ] **Orb Phase ปล่อยให้ timer หมดโดยไม่เลือกการ์ด** → เกมต้องเดินต่อได้ปกติ
      ไม่ค้างรอผู้เล่นที่เลือกไปแล้ว

### C5. อาวุธ  *(Round 1 · Round 3 · Round 4)*

- [ ] **Valor** dash แล้วไม่โดนใคร → **ต้องไม่มีเอฟเฟกต์เด้งที่ตัวเอง**  *(Round 1 · N3)*
- [ ] **Lightning Chain / Storm Bunny** → เอฟเฟกต์ตอนโดน**ขึ้นชั้นเดียว** ไม่ซ้อนสองชั้น  *(Round 1 · N3)*
- [ ] **Cluster Bomb** — ถือไว้แล้วให้ศัตรูตายไกลๆ (หรือเพื่อนฆ่า) → **ต้องไม่มีระเบิด**

- [ ] **Bunny Hop** กด dash แล้วตายกลางทาง → **ตัวต้องหยุด** ไม่พุ่งต่อจนจบระยะ  *(Round 4)*
