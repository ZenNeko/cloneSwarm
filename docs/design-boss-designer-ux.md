## 3 · ฟีเจอร์ — เรียงตามคุ้มค่า

### A. ชุดท่าสำเร็จรูป (Palette) · แทนเมนู New/ชื่อคลาส
- แผงซ้ายเรียงตาม **กริยาของผู้เล่น** · ลากลงเลนหรือดับเบิลคลิก = สร้างคลิปที่ playhead
- ท่าสำเร็จรูป = `ScriptableObject` template ที่ **ตั้งค่าให้เข้าท่าแล้ว** + ค่าตามขนาดสนาม (ขนาดวง = % ของรัศมีสนาม)
- เก็บเป็นไฟล์ในโปรเจกต์ (`Assets/ScriptableObjects/BossAction/Presets/`) — ใครสร้างท่าดีๆ คลิกขวา "บันทึกเป็นท่าสำเร็จรูป" ได้ palette ก็โตเอง
- ชุดเริ่มต้น (ประมาณ 12): วงใต้ทุกคน · วงไล่ตาม · กากบาทกลางสนาม · เส้นกวาด · โดนัทรอบบอส · พัดหน้าบอส · ยืนรวม (stack) · แยกกัน (spread) · หันหลัง (gaze) · ต้องเดิน · โซ่ 4 แบบ · Limit Cut

### B. การ์ดแก้ด่วน · แทน Inspector 48 ช่อง
- แต่ละชนิดท่าโชว์ **5–6 ช่องที่แก้บ่อย** เป็นแถบเลื่อนพร้อมหน่วยที่คนเข้าใจ:
  - ขนาด: เมตร **และ % ของสนาม** · ดาเมจ: ตัวเลข **และ % ของ HP ผู้เล่นพื้นฐาน** · เตือน: วินาที
- "ที่ไหน" เป็นคำ: บอส / ทุกคน / คนใกล้สุด / สุ่มหนึ่งคน / กลางสนาม / มุมสนาม ▾ — แปลงเป็น `targetingMode` + `arenaAnchor` ให้เอง
- ปุ่ม **ขั้นสูง ▸** เปิด Inspector เดิม (ไม่ทิ้งของเดิม แค่ถอยไปข้างหลัง)

### C. ▶ เล่นพรีวิว + แถบความปลอดภัย
- ▶/⏸/วนซ้ำ/ความเร็ว · Space = เล่น/หยุด · ในแผนผังสนามวงค่อยๆ เติมสีตามเวลาเตือน แล้วกะพริบตอนระเบิด
- **แถบความปลอดภัย** ใต้ timeline: % พื้นที่สนามที่ไม่มีดาเมจ ณ แต่ละช่วงเวลา (คำนวณจาก `ResolveWave` + ขนาดทรงที่มีอยู่แล้ว)
  - ต่ำกว่า 10% ขึ้นแดง "เกือบไม่มีที่หลบ" · 0% = "หลบไม่ได้" — จับแพตเทิร์นที่ตายแน่ก่อนกด Play
- **เวลาต่อรอบ × จำนวนรอบที่คาด** ของเฟส: HP ช่วงนั้นของบอส ÷ DPS ทีมสมมติ (ตั้งได้) → "เฟสนี้เล่น ~3 รอบ"

### D. แก้บนแผนผังสนาม (direct manipulation)
- ลากตัววง = ย้าย (ตั้ง offset / เลือกมุมสนามที่ใกล้สุด) · ลากขอบ = ขนาด · ลากด้ามหมุน = มุมของเส้น/พัด
- คลิกที่ว่างในสนามขณะถือท่าจาก palette = วางท่าตรงนั้น ที่ playhead
- ยืนยันด้วย `ResolveWave` ตัวเดียวกับ server — ภาพกับของจริงยังเป็นสูตรเดียว

### E. ความสุ่มในหนึ่งช่อง · แทนการไปเพิ่ม Roll Definition เอง
- ช่อง "สุ่ม" ในการ์ด: ไม่สุ่ม / พลิกซ้าย-ขวา / หมุนทีละ 90° / เลือกมุมสนาม / เลือกผู้เล่น / สลับลำดับ
- เลือกแล้ว **สร้าง Roll Definition ใน config ให้เอง** (ตั้งชื่อตามคลิป) · ปุ่ม "ใช้ค่าสุ่มเดียวกับคลิป…" สำหรับท่าที่ต้องหมุนไปพร้อมกัน
- พรีวิว 🎲 เดิมยังใช้ได้ · เพิ่มปุ่ม "ดูทุกแบบ" = แผนผังเล็กเรียงทุกผลลัพธ์ที่เป็นไปได้

### F. ปลอดภัยเป็นค่าเริ่มต้น
- ลาก/สร้าง/Duplicate = ได้ action **ของคลิปนั้นตัวเดียว** เสมอ (ปัจจุบัน Duplicate ชี้ action เดิม)
- จะแชร์ต้องกด 🔗 "แชร์กับคลิปอื่น" เอง · คลิปที่แชร์มีไอคอนโซ่ + ขอบสีเดียวกัน
- เฟสแบบ list เก่าแปลงเป็น timeline อัตโนมัติตอนเปิด (มีแค่แบบเดียวให้เรียน)

### G. ▶ ทดสอบในเกม เฟส N
- ปุ่มบน toolbar: เข้า Play Mode ในฉากทดสอบ → เกิดบอสด้วย config นี้ **ข้ามไปเฟส N ทันที** · ผู้เล่นอมตะ (สลับได้) · วน timeline
- ลดวงวน "แก้ → กด Play → รอ 15 นาที / DevTools" เหลือคลิกเดียว

### H. สร้างเวอร์ชันความยาก
- "สร้างเวอร์ชัน Savage…" = ก๊อป config ทั้งชุด + ตัวคูณ (เตือนสั้นลง · ดาเมจ ·  interval) + ผูกเข้า `MapData.TierContent` ให้
- ป้ายบน toolbar บอกว่า config นี้เป็นเวอร์ชันของใคร

### คีย์ลัด
Space เล่น/หยุด · ←/→ เลื่อนคลิป 0.1s (Shift = 1s) · Ctrl+D ก๊อปคลิป · Delete ลบ · 1–9 เลือกเฟส · F = Fit

## 5 · สิ่งที่ไม่เปลี่ยน

- ข้อมูลยังเป็น `BossEncounterConfig` + `BossAction` เดิม — **ไม่มี migration** · ของที่ทำไว้เปิดได้เหมือนเดิม
- runtime (`BossController`, `SpawnAoEActionBase.ResolveWave`) ไม่แตะ — งานนี้เป็นเครื่องมือ Editor ล้วน
- Inspector เดิมยังอยู่หลังปุ่ม "ขั้นสูง"

## 6 · คำถามที่ต้องตอบก่อนเริ่ม — ตัดสินแล้ว (2026-09-24 · ค่าตั้งต้น เปลี่ยนได้)

1. **% HP** เทียบกับ `CharacterData.baseHealth` ที่ต่ำสุดในโปรเจกต์ (ตอนนี้ 100) · ก่อนเกราะ
2. **แถบความปลอดภัย** นับทั้งสนาม (ไม่นับว่าวิ่งไปทันไหม) — ตัวเลขจึงมองโลกในแง่ดีกว่าจริง
3. **ทดสอบในเกม** ใช้ `SampleScene` · runner เริ่ม host เอง (ซีนนี้ไม่มี AutoHost)

### คำถามเดิม

1. ค่าอ้างอิง "% ของ HP ผู้เล่น" ใช้ HP พื้นฐานของตัวละครไหน (ตัวต่ำสุด?) หรือค่าคงที่ที่ตั้งเอง
2. แถบความปลอดภัยควรนับ "ที่ปลอดภัย" ทั้งสนาม หรือเฉพาะรัศมีที่ผู้เล่นวิ่งไปถึงได้ในเวลาเตือน (แม่นกว่า แต่ต้องรู้ความเร็วผู้เล่น)
3. ฉากทดสอบของปุ่ม G: ใช้ `WeaponTestScene` ที่มีอยู่ หรือทำฉากสนามบอสแยก
